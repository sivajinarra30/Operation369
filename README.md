# Operation369
An open-source hub empowering digital content creators.

## Overview
Operation369 is a comprehensive open-source platform designed to streamline digital content creation. It hosts automation tools, management scripts, and web interfaces tailored for creators, video editors, and social media managers.

## Key Features
- **Automation Tools:** Workflows to automate redundant asset exporting and sorting.
- **Creator Hub UI:** A web dashboard for managing creative pipelines and metadata tracking.
- **Open Source Community:** A collaborative space for developers to build modular plugins for creators.

## Tech Stack
- Frontend: HTML5, CSS3, JavaScript
- Future Integrations: AI API models for script and metadata generation.
